## Princípios já levantados — somente como input futuro

- o produto deve funcionar como memória navegável da campanha, não como dashboard SaaS;
- uma tela deve responder uma pergunta principal;
- profundidade deve ser progressiva;
- leitura e edição devem ficar separadas;
- entidades devem ter identidade própria em vez de JSON embutido;
- conhecimento/visibilidade precisa respeitar campanha, personagem e ownership;
- grafo futuro deve abrir localmente e progressivamente, nunca como "teia inteira" por padrão;
- referências visuais canônicas precisam poder servir de base para arte futura.
